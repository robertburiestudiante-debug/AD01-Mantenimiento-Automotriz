## Tecnologías e Implementación
* **Frontend & UI:** HTML5 semántico, CSS3 con variables personalizadas (paleta *Forza Motorsport*) aplicando las 10 heurísticas de usabilidad de Jakob Nielsen, Bootstrap 5.3 y SweetAlert2.
* **Lógica JavaScript:** Manipulación del DOM, persistencia en `localStorage`, validaciones con expresiones regulares (`RegExp`), diccionarios de estado y métodos iterativos (`for`, `for...of`, `forEach`, `find`, `filter`, `map`).
